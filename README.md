# Day 5 – Excel Data Analysis

## Project Overview
This project focuses on analyzing the Sample Superstore dataset using Microsoft Excel. It includes data analysis with Excel formulas, sorting, filtering, and PivotTables to identify important business insights.

## Dataset
- **Dataset:** Sample Superstore
- **Records:** 9,994 rows
- **Columns:** 21

## Tools Used
- Microsoft Excel
- Excel Formulas
- PivotTables
- Sorting and Filtering

## Workbook Structure
The Excel workbook contains the following sheets:

1. **Raw Data** – Original dataset.
2. **Working** – Data analysis and formula calculations.
3. **Summary** – Key performance indicators and business insights.
4. **Pivot_Region_Sales** – Region-wise sales analysis.
5. **Pivot_Category** – Category-wise sales analysis.
6. **Pivot_Region_Profit** – Region-wise profit analysis.
7. **Pivot_Monthly_Sales** – Monthly sales analysis.

## Excel Functions Used
- SUM()
- SUMIFS()
- YEAR()
- MONTH()
- DATE()

## Key Business Insights

- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Quantity Sold: 37,873
- Highest Sales Region: West
- Highest Sales Category: Technology
- Highest Profit Region: West

## Analysis Performed
- Calculated total sales, profit, and quantity.
- Analyzed sales performance across different regions.
- Compared sales across product categories.
- Evaluated profit by region.
- Analyzed monthly sales trends using PivotTables.

## Conclusion
This Excel data analysis project helped identify important business trends and performance metrics from the Sample Superstore dataset. The West region generated the highest sales and profit, while Technology was the top-performing product category. PivotTables and Excel formulas made it easier to summarize and understand the data.
